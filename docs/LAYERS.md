# 獨立美術圖層與動作（v3）

預設角色使用 `public/assets/characters/hana/parts-v3/` 的透明 PNG，每張保持 1254 × 1254。14 個可編輯圖層包含後髮、頭部／身體、左右上臂、左右袖子、左右手掌、上衣、裙襬、眼睛、嘴型、中髮及前髮。

| 部件 | 素材 | 綁定 |
| --- | --- | --- |
| 後髮 | `hair-back.png` | 補全頭部與軀幹後方的完整髮量 |
| 頭部與身體 | `body.png` | 原註冊座標，保留表情身份 |
| 上衣 | `bodice.png` | 完整淺色布料，不以膚色門檻切除 |
| 裙襬 | `skirt.png` | 腰部與上衣重疊 36 px |
| 左右上臂 | `arm-upper.png` | 共用一張乾淨原件，左側於渲染時鏡像 |
| 左右袖子 | `sleeve.png` | 補繪髮絲遮擋區，上臂接縫重疊 32 px |
| 左右手掌 | `hand-open.png` | 獨立五指手掌，只平移與旋轉 |
| 中髮 | `hair-middle.png` | 左右對稱髮束，中央保持自然透明 |
| 前髮 | `hair-front.png` | 保留原有瀏海與單側月亮髮飾 |

後髮、中髮、乾淨袖臂及手掌由內建 imagegen 編輯補繪；原始素材留存。`scripts/package-layers-v3.ts` 只做尺寸註冊與幾何邊界包裝，不再用色差把粉色陰影當成皮膚挖掉。上衣與袖子內部的透明孔洞檢查均為 0。髮束外圍捲曲之間的透明空隙是自然輪廓，不應填成整塊實心。

## 關節與變形

左右肩關節位於 (797,474) 與 (457,474)，以 x=627 為鏡像軸；上臂與前臂長度固定。袖子使用沿骨骼長度連續的肘部權重，取代會突然切換的最近骨骼分類。手掌不進入袖子的變形網格，不再切換或交叉淡入不同手部姿勢。`armRaise`／`armRaiseLeft` 控制抬臂，`wristWave`／`wristWaveLeft` 控制手腕擺動。

合成畫布左右各有 160 px 透明緩衝區，抬臂途中不再截斷手指。獨立髮束與裙襬各自變形，風力不會把袖子或手掌當成髮絲拉扯。手掌排在髮束前方，避免髮絲穿過手指。

結構對稱包含左右臂的素材、長度與關節配置，以及左右髮束的構造；服裝裝飾、單側髮飾與原有臉部畫風仍保留細微不對稱。這是 2D 正面角色，沒有生成新的側面／背面視角。

## 動作與逐幀檢視

11 種預設：輕柔待機、揮手招呼、開心說話、風吹衣襬、點頭回應、輕輕搖頭、眨眼微笑、歪頭好奇、左右環顧、左手招呼、雙手歡迎。預設採用平滑插值，起點與終點姿態一致。

編輯器時間軸的「上一影格」「下一影格」會暫停播放並以專案 FPS 精確跳轉。`node --import tsx scripts/audit-motions.ts` 逐幀渲染每個 6 秒、30 FPS 動作，含終點共 181 幀，生成 `outputs/motion-qa/index.html`、每幀 WebP、每秒透明 PNG、影格總覽與 JSON 檢查結果。頁面可用左右鍵停格檢視。

## 編輯與相容性

每個圖層可隱藏、鎖定、變更透明度、位置、旋轉、縮放、排序及替換 PNG。左右共享來源圖，但圖層控制獨立。自訂替換左右手部素材時使用右側的註冊座標；左側於渲染時鏡像。

原本內建 v2 專案會升級素材並保留圖層調整、參數、動畫與自訂配件。自行替換或內嵌素材的舊專案不自動覆寫。舊 `parts/` 及 `waveSrc` 播放方式仍保留以相容既有檔案。

`mesh` 仍是整體造型網格，尚無逐部件 UV／多級變形器編輯器；眼睛、嘴型仍以註冊的局部表情 PNG 控制。
