## 逐幀品質

11 種動作各 6 秒，以 30 FPS 渲染 0～180 幀，含終點共 **1,991 幀**。使用 Chromium 實際播放器與正式 PNG 素材，停用隨機眨眼與即時平滑，使每幀能重現。

- 每幀確認左右邊界無角色 alpha，避免抬手過渡被裁切。
- 每幀檢查軀幹六處 alpha 覆蓋，避免衣服與腰部露出透明洞。
- 骨架測試在同一組 1,991 幀驗證左右鏡像、固定骨長、手掌點距離不變、移動速度及循環端點一致。
- 素材測試確認部件為 1254×1254 RGBA；衣身、袖子、手掌沒有超過五個像素的封閉透明洞。髮捲之間的自然間隙不作為破洞判定。
- 目視看完涵蓋所有影格的接觸表；另檢查抬手中段、最高點、左右手與雙手姿勢的大圖。沒有發現手指拉長、貼圖重影、袖口斷開或手掌裁切。
- Canvas 備援渲染另保存六個抬手階段；中段與最高點大圖已目視確認。

逐幀圖片、滑桿檢視頁及接觸表位於 `outputs/motion-qa/`；`report.json` 記錄自動檢查與目視範圍，`visual-review.md` 記錄檢視結論。每幀保存 800×640 WebP，每秒另保存透明 PNG。接觸表用來看所有幀的輪廓與連續性，大圖用來看手指及接縫細節；沒有將縮圖檢視描述為每幀原尺寸檢查。

## 範圍

角色仍為正面 2D 圖層模型，轉頭是有限角度的變形。左右肩、手臂、袖子、手掌採鏡像結構；保留原設計的單側月亮髮飾與衣裙裝飾。眼睛與嘴巴仍使用表情覆蓋。這輪逐幀檢查涵蓋內建動作與預設圖層設定，自訂極端參數或自行替換素材需另外檢查。

## 重現

先啟動 `npm run dev`，依終端網址設定 `TEST_BASE_URL`：

```sh
npm test
npm run build
TEST_BASE_URL=http://127.0.0.1:5174 npm run test:e2e
TEST_BASE_URL=http://127.0.0.1:5174 node --import tsx scripts/audit-motions.ts
```

重新執行逐幀腳本會產生新圖與報告，目視狀態回到 `pending`，需要重新檢視後才能標記完成。
